# Avaliar uma fonte por regra

No MVP, cada regra avaliará uma única métrica de uma única fonte. Observações provenientes de health checks e aplicações, ou de diferentes locais, terão avaliações independentes e poderão originar incidentes distintos, posteriormente relacionados como duplicados quando necessário. Combinações entre fontes, como quórum de regiões, ficam adiadas até existir necessidade concreta.
