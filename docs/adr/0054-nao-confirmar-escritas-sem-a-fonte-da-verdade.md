# Não confirmar escritas sem a fonte da verdade

Quando a fonte principal de dados estiver indisponível, nenhuma escrita será confirmada: sinais e comandos serão recusados para nova tentativa e a interface operará somente para leitura. Visões antigas poderão permanecer acessíveis apenas com indicação clara de desatualização, e a página pública manterá a última informação publicada com seu horário. A recuperação não exigirá reconciliar alterações temporárias que nunca foram persistidas com segurança.
