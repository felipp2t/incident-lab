# Usar papéis fixos por organização

O controle de acesso usará os papéis fixos `admin`, `respondente` e `visualizador`, com permissões predefinidas pelo sistema. O papel pertencerá ao vínculo entre usuário e organização, permitindo que a mesma pessoa tenha papéis diferentes em organizações distintas; administradores poderão alterar o papel dos membros, mas não a matriz de permissões. Ser responsável principal por um incidente será uma atribuição operacional temporária e não um papel de acesso.
