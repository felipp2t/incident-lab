# Consultar Organizações para resolver a audiência

Comunicação consultará diretamente a área de Organizações ao criar notificações para descobrir membros ativos com papéis elegíveis, sem manter uma cópia própria de usuários e papéis no MVP. Cada e-mail validará novamente a elegibilidade antes do envio; falha na consulta manterá o trabalho pendente para repetição, sem afetar o incidente. A política de audiência continuará pertencendo a Comunicação, e `IncidenteAberto` não transportará uma lista de destinatários.
